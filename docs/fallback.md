# If the sermon pipeline isn't available

The pipeline only prepares files; it never publishes anything. On any week it isn't run, use the
church's usual process:

1. Paste the YouTube link of the service into SermonShots and trim it to the sermon.
2. Copy SermonShots' YouTube description into the video's description in YouTube Studio.
3. Download the podcast audio from SermonShots and upload it in Spotify for Creators, with
   SermonShots' short description.
4. Export any clips from SermonShots as usual.

Nothing about the church's accounts depends on the pipeline, so there is nothing to undo or switch
back.
